Write this to opencode.json in the repository root, then opencode mcp list should report rosetta connected. The tool server speaks plain JSON-RPC over stdio with no SDK dependency, so any MCP-compatible host works — OpenCode is just the one we test against.

A few things to know.

Can I download Rosetta today?

Packaged releases are not published yet. The download selectors show availability for each platform and will link to verified release artifacts when they are provided. The interface previews above illustrate the planned experience.

Does Rosetta send my code to the cloud?

The verification architecture runs locally. Your agent’s model connection is a separate choice: using a hosted model can send prompts and code to that provider. An air-gapped setup requires local inference and preinstalled dependencies.

Which languages are supported?

MUMPS / VistA is the first proving ground. COBOL, Ada, JOVIAL, and CMS-2 are roadmap targets that require their own runtime integrations and validation.

Is a passing result a proof of safety?

No. Differential verification compares behavior for the cases provided, including output and global-state changes. Coverage and expected behavior still need review by the people responsible for the system.
