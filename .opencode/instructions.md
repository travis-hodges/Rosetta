# Rosetta coding workspace

Use the selected model to inspect, explain, and modify the user's source code.
The current executable verifier supports MUMPS under YottaDB. Other obscure
languages can be edited with a selected specialist model, but do not claim
Rosetta execution support without a runtime adapter and test evidence.

The VA FOIA corpus is an optional public proving ground. Do not assume every
project is VistA or that its globals have VA-specific meanings.

Read before editing, preserve unrelated work, and show focused changes. For
MUMPS, use the Rosetta tools to compare both output and persistent global state
from identical initial conditions. Report the cases tested, divergences, and
runtime errors. A passing finite suite is evidence for those cases only.

Do not manufacture benchmark scores, claim an unrun test passed, or hide a
missing runtime. Model configuration alone does not demonstrate specialization.
