# Rosetta pitch prototype

This dependency-free browser presentation is a blueprint for Rosetta's pitch. It intentionally uses placeholder copy so the visual rhythm and animation system can be decided before the narrative is finalized.

## Run it

From the repository root, run `npm run dev`, then open `http://127.0.0.1:5173/pitch/`.

## Controls

- Right arrow, down arrow, space, or Page Down: next slide
- Left arrow, up arrow, or Page Up: previous slide
- Home or End: first or last slide
- `O`: toggle the overview grid
- `M`: pause or resume motion
- `R`: replay the current slide's entrance sequence
- Swipe or mouse wheel: move between slides

## Visual and motion system

- Cream `#eeeee7`, charcoal `#242720`, acid `#f2ff66`, and divergence red `#ff5c4d`
- Arial display type, Georgia italics, and system monospace evidence labels
- Hairline grid, oversized typography, sliced metal geometry, runtime terminals, and proof-state signals
- Vertical clip transitions with timed internal scenes rather than generic fades
- Reduced-motion support that preserves each slide's final state

## Storyboard

1. Opening thesis and metallic system object
2. Stakes expressed as a severe evidence wall
3. The confident failure mode
4. The mechanical verification loop
5. Side-by-side money moment
6. Product surface around the verifier
7. Reserved slot for measured benchmark evidence
8. Closing line and direct handoff to the demo

The benchmark slide contains no invented performance claims. Replace placeholders only after the narrative and measured results are ready.
