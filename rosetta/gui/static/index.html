05 / Train

The verifier is the reward.

Comprehension labels come from static analysis, so none of them can be wrong the way a model-generated label can be wrong.

Training data generation runs in the terminal, deliberately. Each step below either reads the corpus or writes a file, and none of them needs a browser.

rosetta train labels     # comprehension pairs from static analysis
rosetta train sft        # chat-format JSONL, split-checked
rosetta train grader     # the verifier as a reward function

Why there is no “Fine-tune” button

Submitting a training set means a provider account, a spend decision, and data leaving this machine. In the deployment Rosetta is built for, it cannot leave at all. So the loop closes through the surfaces that already exist:

rosetta model add tuned provider/ft:your-model-id
rosetta bench run --model tuned

A fine-tuned model re-enters through Models and is measured by Runs. No new concepts, and no number that did not come from a real run.
