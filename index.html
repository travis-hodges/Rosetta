How it works

You don't need a corpus
if you have an interpreter.

Stop teaching the model the language. Give it a way to check its own work. Everything below runs locally, offline, against the customer's own runtime.

01 Snapshot

Freeze the world.

Capture global state by copying YottaDB .dat region files. Sub-second, so thousands of cycles stay affordable.

02 Apply

Load the candidate.

Compile the proposed routine into the environment. A compile failure is a result, not an exception to swallow.

03 Execute

Drive both versions.

The same input suite runs against baseline and candidate, each from clean state, each restored afterward.

04 Diff

Compare output and state.

In MUMPS the globals are the database. A routine can return the right value and still corrupt ^DPT. Output-only comparison misses it.

One component does four jobs

  1. Grades the benchmark
  2. Serves as a tool the agent calls
  3. Generates verified training data
  4. Acts as the reward function for fine-tuning

Which is why the method is corpus-agnostic. Give Rosetta a runtime for any obscure language and it bootstraps a competent agent from zero training data.

THE NUMBER THAT MATTERS

False-confidence rate.

How often the model asserts correctness while verification fails. It quantifies “fluent and confidently wrong” — exactly what a program office fears, and exactly what Rosetta detects.

DISCIPLINE

Split routines, not tasks.

Two tasks from one routine share structure and identifiers. The 70/30 partition is written once to split.lock.json and never rewritten. If asked “did you train on your eval?”, the answer is a file, not a claim.

STATED LIMITATION

Mutation is a proxy.

Mutation repair over-represents localized single-line bugs and under-represents cross-routine change and genuine feature addition. Hand-authored tasks supplement it. We would rather name this than have you find it.

Deployment

We never need
to see your code.

The verifier runs where the code already lives. That is not a policy commitment — it is how the thing is built.

01 / AIR-GAPPED

Self-validating on the high side.

Nothing leaves a classified enclave without a cross-domain review, so no telemetry comes back. The customer runs the scoring themselves, in place, and reports a number.

02 / PORTABLE

MCP, not a walled harness.

The tools are exposed over MCP and work with any host agent. If the labs absorb the agent layer, the verifier is still the part that matters.
